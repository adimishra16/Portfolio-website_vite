# Aditya Mishra — Full Stack Portfolio

Personal portfolio for **full stack developer** roles.

## Theme

**Blueprint Studio** — cool paper grid, ink typography, safety-orange signal accent.

## Stack

- Vite + React 18 + TypeScript
- Tailwind CSS
- React Router

## Content

Edit `src/content/portfolio.ts` for copy, projects, skills, and links.

## Scripts

```bash
npm install
npm run dev
npm run build
```
